## Power BI – Sales Data Analysis

### 1. Data Cleaning and Loading 
- Imported CSV data and edited using Power Query Editor.
- Handled missing values.
- Removed duplicate records.
- Standardized OrderDate format.
- Loaded the cleaned dataset into Power BI.

### 2. Visualizations and Insights 
- **Pie Chart:** Order distribution across regions.
- **Column Chart:** Top 5 trending products by order count.Filtered using filter option for top 5.
- **Line Chart:** Profit trends over time.

### 3. DAX Calculations
- **Calculated Table:** EastRegionOrders – Created custom table that Filters East region orders only.
- **Calculated Column:** ProfitCostDifference – Calculates Profit minus Cost.
- **Measure:** TotalProfit – Calculates total profit earned.

Created an interactive Power BI dashboard to analyze sales performance, using different visuals and slicers.
